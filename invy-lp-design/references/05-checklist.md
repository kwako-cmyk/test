# 書き出し前チェック

zip を渡す前に全項目を確認する。

## 構成

- [ ] 全ブロックがカタログ（`03-cms-blocks.md`）のパーツになっているか
- [ ] ページ専用パーツを反対のページに置いていないか（ビルドがエラーで止める）
- [ ] 1ページ1行動になっているか（【2】）
- [ ] 特典がファーストビューの直後にあるか
- [ ] 規約 → フッター → フローティングバナーの順で末尾に来ているか
- [ ] カタログで実現できない要望を、構成に混ぜずに `outOfCms` に書いたか

## 事実

- [ ] `A-invy-facts.md` に反する導線・表現がないか（ページ上で予約できる、特典が自動で届く、など）
- [ ] CTA ごとに文言・遷移先・計測方法の3点が決まっているか。決まっていないものをハンドオフに書いたか
- [ ] 特典の条件を注記で併記したか
- [ ] 仮説を事実として書いていないか

## 文章

- [ ] 本文1文40字以内、1ブロック3文までか
- [ ] ボタン文言が動詞で終わり、1行に収まっているか
- [ ] 禁止表現（絶対表現・根拠のない No.1・効果効能の断定）がないか
- [ ] 内部用語（ゲスト、CV など）がページ上に残っていないか
- [ ] 見出しで宣言した数と項目数が一致しているか

## デザイン

- [ ] ビルドの「要確認」を全部読み、直せるものを直したか
- [ ] 見出しの泣き別れ・はみ出しが残っていないか
- [ ] デザイン上に作業用の表示（番号・バッジ・注釈）を描いていないか
- [ ] 配色はワイヤーか、指示されたブランド色か
- [ ] 支給されていない画像を作ったり、無関係な画像で埋めたりしていないか

## 渡すもの

- [ ] `--zip` で一式（Figma 用 SVG・入稿シート md/csv・プレビュー・spec.json）を出したか
- [ ] Figma への取り込み方を1〜2行添えたか
- [ ] ハンドオフ（仮説・未確定事項・画像素材の依頼・CMS外の要望）をチャットで箇条書きにしたか
