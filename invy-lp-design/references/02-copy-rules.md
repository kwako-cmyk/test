# LP の文章規則

読み手はエンドユーザー（紹介者・ご紹介を受けた方）。スマホで流し読みされる前提で書く。

## 1. 長さ

- 本文は **1文40字以内、1ブロック3文まで**。375pt 幅で本文 14pt は1行約23字。3行を超えると読まれない
- 見出しは2行以内。改行位置は `\n` で指定し、1〜2文字だけが次の行に落ちる「泣き別れ」を作らない（ビルドが警告する）
- ボタン文言は **動詞で終える**（「紹介する」「クーポンを受け取る」）。1行に収める（目安13字以内）

## 2. 特典の書き方

- 金額・割引率を大きく、条件は注記（`benefits` の `note`）で必ず併記する
- 条件を本文に埋めない。「※ご紹介を受けた方のご来店が確認できた時点で付与」のように注記で分ける
- 紹介者とご紹介を受けた方、両方の特典を並べて書く（片方だけにしない）

## 3. 禁止表現

- **invy の提供範囲を超える約束**：「このページから予約完了」「特典は自動で届きます」など。`A-invy-facts.md` を確認する
- **絶対表現**：「必ず」「誰でも」「100%」「無料で◯◯し放題」。条件がある特典は条件を書く
- **景品表示法・業界規制に触れる表現**：「最安」「No.1」（根拠なし）、医療・美容の効果効能の断定。不安なら表現を弱めて【7】に確認事項として書く
- クライアント固有の禁じ手（【1】-4）

## 4. 用語

エンドユーザー向けの言葉に直す。

| 内部用語 | ページ上の表記の例 |
|---|---|
| 紹介者 | あなた／ご紹介くださる方 |
| ゲスト | お友だち／ご紹介を受けた方 |
| CV・成果地点 | ご来店・ご予約・ご契約など、実際の行動名 |
| インセンティブ | 特典 |
| 紹介URL | 紹介用のURL／あなた専用のURL |

## 5. 数の一致

「3つのステップ」と書いたら、流れのステップを3つにする。見出しで宣言した数と、ブロック内の項目数を一致させる。
