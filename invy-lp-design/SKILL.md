# invy 紹介LP（CMS テンプレートブロックで組む）

最終的な着地は **invy CMS への入稿**。CMS で使えるのはテンプレートのブロックだけなので、
**ページは必ずブロック庫（`blocks/`）のブロックを組み合わせて作る**。ブロック庫に無い形は作らない。
実現できない要望は、デザインに混ぜずに「CMS外の要望」として別に伝える。

ブロック庫の正は Figma「テンプレート」ページ（fileKey `1UwJ64MnV8cHs9F39pSAeH`、page `899:3873`）。
各バリエーションを HTML ブロック＋メタ情報＋スクリーンショットとして格納している（68種）。

## このスキルでできる3つのこと

| 依頼 | やること | 出すもの |
|---|---|---|
| **① 構成案**（「構成案を作って」「ページを組んで」） | 指示に合わせてブロック庫からブロックを選び、文言を入れて組み上げる。画像・色は付けない（グレースケール） | 構成案 HTML（`--wire`）と構成表 |
| **② デザイン**（「デザインして」「色を付けて」） | ①の構成に、Main / Sub の色・フォント（4種）・画像を当てる。グレーの画像枠を埋める | デザイン HTML → Figma に書き出し |
| **③ 修正**（「デザインを修正したい」「ここを直して」） | **まず「元のデザインを教えてください」と返して止まる**。場所（Google Drive など）を教えてもらったら読み込み、ブロック庫の組み合わせとして HTML に起こし直してから、指示どおりに直す | 修正後の HTML → Figma に書き出し |

どれから頼まれても、中身は同じ **ページ設計書（`page.json`）** で表す。設計書が正、HTML と Figma はその表現。

## 実行前に必ず読む

| ファイル | 内容 | いつ |
|---|---|---|
| `references/01-flow.md` | 3つの流れの手順と、止まるポイント | 最初に必ず |
| `blocks/CATALOG.md` | ブロック一覧（何のブロックか・入力項目・画像サイズ・繰り返し） | 構成を組む前に必ず |
| `references/page-spec.md` | page.json の書き方と compose.py の使い方 | page.json を書く前に必ず |
| `references/A-invy-facts.md` | invy の事実と制約（CTA の遷移先・計測方法） | 構成と文言を書く前に必ず |
| `references/02-copy-rules.md` | LP の文章規則 | 文言を書くとき |
| `references/figma-write.md` | Figma への書き出し手順（動作確認済みのコード） | Figma に書き出すとき |
| `references/05-checklist.md` | 出す前のチェック | 渡す前に必ず |
| CMS 制約表（Google スプレッドシート。場所は `references/config.json`） | ブロックごとの個数・文字数・画像サイズの制約 | 構成を組むたびに読む（人が随時埋めていく） |

## 守ること

- **ブロックはブロック庫から選ぶ。** HTML ブロックの構造・CSS は書き換えない。変えてよいのは文言・繰り返しの個数・画像・色（Main / Sub）・フォントのモードだけ
- **制約表を毎回読む。** 埋まっている制約（例：スライダーは3枚以上）は必ず守り、compose.py の警告をゼロにしてから渡す。空欄の制約は推測で決めない
- **フォント**：日本語は Noto Sans JP（ゴシック）／Noto Serif JP（明朝）、英数は Roboto。太さは「標準／細め」。この4パターン以外のフォントを使わない
- **色**：Main / Sub の2色だけを決める。テンプレートの色スタイル（Figma の Main / Sub）自体は書き換えず、複製したブロックだけに当てる
- **画像**：支給された素材だけを使う。無ければグレーの枠のまま渡し、必要な画像と推奨サイズを伝える。画像を生成・捏造しない
- **修正の依頼では、元のデザインを読むまで手を付けない。** 記憶や推測で元のデザインを再現しない
- 事実確認が要ること（特典の条件、遷移先 URL、計測方法）は推測で確定させず、未確定として残す
- HubSpot などのコネクタでクライアント情報を調べる場合は、組織の接続先確認ルールに従う

## ファイル構成

```
invy-lp-design/
├── SKILL.md
├── blocks/
│   ├── CATALOG.md          ブロック一覧（scripts/catalog_md.py で生成）
│   ├── CONTRACT.md         ブロック HTML・メタ情報の書き方
│   ├── inventory.json      ブロック ID ↔ Figma ノード
│   ├── _base.css           共通 CSS（色・フォント・テキストスタイル）
│   ├── html/<id>.html      HTML ブロック（グレースケール）
│   ├── meta.json           ブロックごとの入力項目・画像枠・繰り返し・色の役割
│   └── shots/<id>.png      Figma のスクリーンショット（見た目の正）
├── references/
│   ├── 01-flow.md  02-copy-rules.md  05-checklist.md  A-invy-facts.md
│   ├── page-spec.md  figma-write.md  config.json
├── scripts/
│   ├── compose.py          page.json → ページ HTML（構成案／デザイン）＋制約チェック
│   ├── constraints.py      制約表の雛形づくりと読み込み
│   └── catalog_md.py       blocks/CATALOG.md の生成
└── assets/
    └── sample_page.json    記入例
```
